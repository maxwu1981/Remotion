Claude Code 怎麼安裝？（Mac／Windows 快速檢查表）

不需要先裝 Node.js／npm——這是舊教學留下的迷思。官方原生安裝法一行指令搞定，且會自動在背景更新。

macOS／Linux（終端機 Terminal）curl -fsSL https://claude.ai/install.sh | bash
Windows（PowerShell —— 注意提示符要是 PS C:\>，不是 C:\>）irm https://claude.ai/install.ps1 | iex
  • 指令跑完後，打 claude 啟動，瀏覽器會自動跳出完成登入
  • 回終端機應該看到：版本號＋模型名＋你目前所在的資料夾
  • Windows 使用者建議順手裝 Git for Windows（官方建議，讓工具更齊全）

👉 判斷是不是開對 PowerShell：提示符開頭有 PS 才是 PowerShell；只有 C:\> 沒有 PS 的是 CMD，貼 irm 指令會報錯。

常見問題與解法

安裝指令貼了沒反應／報錯

先檢查網路連線，逐字重新貼一次指令（複製貼上時容易漏字元）；若仍失敗，依官方 troubleshoot 頁面的指引排查。

打 claude 出現「找不到指令」

最常見也最簡單的解法：把終端機整個關掉、重新打開再打一次 claude。

Windows 貼指令報 'irm' is not recognized

代表你開到了 CMD，不是 PowerShell。回去用開始鍵搜尋「PowerShell」重新開啟，提示符出現 PS 才是對的視窗。

額度用完了怎麼辦？

這不是故障——Claude Code 有使用額度限制，用完等 app 顯示的重置時間過後就會恢復。緩解方法：把幾個小任務攢成一批一次交代，比一件一件分開問更省額度；一開始也別急著裝一堆第三方外掛，那很吃額度。

資料安全嗎？它會不會亂刪我的檔案？

Claude Code 官方預設「動任何檔案前都會先徵求同意」，你按了才會執行。三條安全家規：①新任務先在練習資料夾試 ②重要資料先備份再讓它碰 ③看不懂它要做什麼，先按「否」再問清楚。網路上的第三方 skill／外掛品質不一，安裝前務必先確認來源。

👉 萬用救援法：把完整錯誤訊息全選複製，貼到 claude.ai 網頁版 問「我在裝 Claude Code 時遇到這個錯誤，請一步步教我修」——裝到一半沒有本機助手時，網頁版就是你的救援隊。
