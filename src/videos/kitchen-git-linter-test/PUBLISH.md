## 描述（problem → solution + 具體結果；實體講清楚）
Git、Linter、測試——這三個工程師天天掛在嘴邊的詞，到底是什麼？
這支用一個「開餐廳廚房」的故事，把三個詞講到小白也秒懂：
• Git ＝ 時光機（後悔藥）：手滑把整鍋湯搞砸，一鍵倒回 3 分鐘前，不用重熬 8 小時。
• Linter ＝ 處女座糾察隊：強制每個廚師刀工、衛生一模一樣，菜才不會忽鹹忽淡。
• 測試 ＝ 皇家試毒官：上菜前先試毒，改版也先驗，防止把招牌菜改成毒藥（回歸測試）。
三樣都有＝頂級廚房團隊；一樣都沒有、直接上線＝快逃啊。

❓ Git 是什麼？一句話：程式碼的時光機，能把專案倒回任何一個過去版本。
❓ Linter 有什麼用？自動檢查程式碼風格與低級錯誤，強制團隊統一規格。
❓ 測試在測什麼？確認功能正確，且日後改動不會把原本好的東西改壞（回歸測試）。
