## EP02｜用旅館房卡讓你明白 access token（OAuth 授權）

**描述：**
把密碼交給 AI 才能讓它幫你做事嗎？不用。用旅館故事 70 秒講懂 access token：
❓ access token 是什麼？＝前台發的「房卡」：限定權限、會過期、隨時可撤銷——你的密碼從頭到尾不用交出去。
❓ 跟密碼差在哪？密碼是萬能鑰匙開全部；房卡只開你允許的那幾扇門，交出去的風險小得多。
✅ 適用：第一次授權第三方 App / AI 工具的新手

## EP03｜用洗衣廠後門鑰匙讓你明白 API key

**描述：**
為什麼機器對機器不走 OAuth 發房卡那套？用旅館後門的故事 2 分鐘講懂 API key：
❓ API key 是什麼？＝給「服務」的固定後門鑰匙：不問同意、長期有效——因為它高頻進出、又不涉個人隱私，每趟都認證發卡太荒謬。
❓ 跟房卡（access token）差在哪？房卡給客人、限定、會過期；API key 給服務、固定、長期。
❓ 外洩怎麼辦？立刻換發：發一把新的、舊的作廢——所以 API key 要像金庫一樣收好。
✅ 適用：分不清 API key 和 token 的新手

## EP04｜用門口保安讓你明白 CAPTCHA（人機驗證）

**描述：**
選紅綠燈、勾「我不是機器人」到底在幹嘛？用門口保安的故事 2 分鐘講懂 CAPTCHA：
❓ CAPTCHA 在防誰？防機器人不防你：自動程式一秒能試上千組密碼、灌爆註冊，出一題「人一秒就會、機器人頭痛」的小題就能把它們擋在門外。
❓ 跟認證、兩步驗證差在哪？認證問你是誰、兩步驗證確認真的是你本人、CAPTCHA 只確認你是不是真人——三個站不同關卡。
✅ 適用：每次被驗證圖惹毛、想知道它有什麼用的人

## EP05｜用萬能鑰匙讓你明白密碼安全（密碼管理器＋兩步驗證）

**描述：**
密碼就是你家的萬能鑰匙——一把開全部。用旅館故事 100 秒講懂怎麼顧好它：
❓ 為什麼密碼絕不隨便交出去？一把開全部；OAuth 房卡、API key 之所以存在，全是為了不必交出這把鑰匙。
❓ 同一組密碼到處用會怎樣？一個網站外洩＝小偷拿同一把鑰匙開你所有的門（銀行/信箱/社群）。
❓ 記不住幾十組密碼怎麼辦？交給密碼管理器，你只要記一把主密碼；再開兩步驗證，就算密碼被偷還差你手機那一關。
✅ 適用：還在到處用同一組密碼的人（趕快看）
