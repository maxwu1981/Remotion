## 要生的新圖(4 張,日式動漫、同系列風格)
1. **masterkey**：巨大金色萬能鑰匙發光，照亮/同時解開一整排旅館房門，「一把開全部」的份量感，16:9。
2. **reuse-risk**：同一把金鑰匙被偷偷複製成好幾把，去開好幾扇不同招牌的門(銀行/信箱/社群圖示)，一個壓帽小偷一把抓走，警示感，16:9。
3. **manager**：一個溫暖可靠的「鑰匙保管員」(或保險箱/鑰匙整理櫃)，整齊掛著一大串貼標籤的鑰匙，最前面一把「主鑰匙」發光，16:9。
4. **2fa**：一扇溫馨旅館房門上有兩道鎖——下面一般鑰匙孔、上面一道發光的第二道鎖，旁邊一支手機顯示驗證碼光點對上第二道鎖，16:9。
(hero、keycard 沿用;s8 沿用 masterkey。)
