## ★ 本章知識重心（老闆 2026-07-01 指定）
**先講「為什麼用 API key、而不是 OAuth＋發房卡那套」，再講機制。** 原因＝這種門是①**高頻進出**（服務天天來好幾趟）②**判定不涉個人隱私**（只是例行收送、沒碰誰的私人東西）→ 每趟都跑前台認證＋發臨時卡「太荒謬也沒必要」→ 所以直接給固定後門鑰匙(API key)。**目標：帶聽眾真正理解，不是背名詞。**
