❓為什麼每次開新對話，Claude Code 都不記得我講過的規則？
因為規則沒寫進 CLAUDE.md——它是 Claude Code 每次 session 啟動時唯一會自動讀進 context 的檔案，官方文件明講位置分四層（Managed／User／Project／Local）疊加讀取，不寫在對的位置就等於沒寫。打一句 /init 就能自動生成起始版本。

❓寫了 CLAUDE.md 為什麼 Claude 還是不照做？
最常見的誤區是「什麼都塞進去」——官方文件證實內容超過兩百行反而會讓遵循度下降、Claude 忽略一半。四原則裡的 Specificity 也很關鍵：「用兩個空格縮排」這種具體規則比「格式要寫好」這種模糊說法有效得多。

✅ 適用：已經在用 Claude Code、被「每次都要重講規則」困擾的開發者；想把 coding 規範統一進版控的團隊
🚫 不適用：只是想要 Claude 記住聊天內容本身——那是 Auto Memory 自動寫的，只讀前 200 行或 25KB，跟本片教的手寫 CLAUDE.md 是兩回事
