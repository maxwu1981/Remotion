## 描述（problem → solution + 具體結果；實體講清楚）
API、SDK、函式庫——這三個詞天天有人搞混，到底差在哪？
這支用「去餐廳吃飯」的故事，一分鐘講到小白也分得清：
• API ＝ 隔窗口點餐：你看菜單、跟服務生點，廚房幫你做好端出來，你完全不用進廚房。
• SDK ＝ 一整盒料理包：食材＋食譜＋工具全打包，讓你在自己家的廚房把菜組出來。
• 函式庫 ＝ 一罐現成醬料：不用從頭熬，要哪個味道開罐倒進去，立刻就有。
一句話分清：API 是「人家幫你做」，SDK／函式庫是「把東西搬回你家自己煮」。
最容易搞混的釐清點：SDK 跟 API 不是二選一——SDK 盒子裡，常常就裝著幫你打 API 的工具。

❓ API 是什麼？一句話：隔著窗口點餐，你不用知道廚房怎麼煮，照菜單點、它把結果端給你。
❓ SDK 跟函式庫差在哪？SDK 是「整盒帶回家自己組的料理包」（含工具與範例），函式庫是「一罐現成醬料，要哪味直接拿來加」。
❓ SDK 跟 API 是二選一嗎？不是。SDK 通常把「呼叫 API 的工具」一起打包進去，兩者常常一起出現。
