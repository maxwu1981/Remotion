# EP01 練習包 — 非工程師的 Claude 自動化課

跟著 YouTube《非工程師的 Claude 自動化課 EP01》操作用的下載包。裝好 [Claude Code](https://claude.ai/pricing) 之後，照下面兩步就能重現影片裡的第一個自動化。

## 1. 產生練習資料夾

```
node generate-practice-folder.mjs
```

會在目前目錄建一個 `claude-練習` 資料夾，裡面塞 87 個雜檔（截圖、照片、文件、發票、簡報、試算表⋯）。全部是空白示意檔，可以放心讓 Claude 練手，不會動到你真正的資料。

## 2. 對 Claude 說（複製貼上即可）

**第一句話，確認連上了：**
```
這個資料夾裡有哪些檔案？幫我照類型分類概述一下。
```

**第一個自動化：**
```
請把這個資料夾裡的檔案照類型整理進分類資料夾（例如：圖片、文件、PDF）。
先給我整理計畫，等我說「好」再動手。過程中要刪除任何東西都必須先問我。
做完後列一張清單：每個檔案從哪裡搬到了哪裡。
```

## 3. 之後任何任務都能用的萬用模板

```
我完全不會寫程式，這是我第一次用 Claude Code，請把我當新手帶。
我已經建了一個練習資料夾，等一下的任務只准在這個資料夾裡進行。
任務：〔把你想自動化的事寫在這裡，例如：把檔案照類型整理進分類資料夾〕
規則：
1. 先給我步驟計畫，等我回覆「好」才開始動手
2. 要刪除或覆蓋任何檔案，一律先問我
3. 做完後用清單報告你動了哪些檔案
4. 我看不懂的名詞，用生活比喻解釋給我聽
```
