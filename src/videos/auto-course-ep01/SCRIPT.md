## 三、故事弧（第一人稱）

為何有此議題→AI 助手已經能幫你做電腦上的雜事，但所有教學都預設你是工程師。
誰遇到→我頻道後台和對標片留言區裡，最多人問的不是功能，是「我不會寫程式，我真的能用嗎」「Windows 呢」「卡住了」。
影響→零基礎的人卡在第一步（終端機），永遠享受不到後面的自動化紅利；有人硬上還出事（下載夾被打散慘案）。
為何別人解不掉→現有爆款教學（對標三支）要嘛只教 Mac、要嘛講功能目錄不講「卡住怎麼辦」、要嘛預設你懂術語。
你怎麼解→這一堂 40 分鐘保姆級跟操：Mac+Windows 都教、每步有✅檢核點卡讓你確認有跟上、每章附「常見卡點急救」段、第一個任務刻意設計成「先建練習資料夾」保證不出事。
哪裡不同→我自己就是用這套流程讓 Claude 天天替我發文、上架、做影片的人（頻道 60+ 支片全是它做的），教的是驗證過的路，不是讀文件。
怎麼證明→片尾 before/after：亂糟糟練習資料夾 → 一句話 3 分鐘分類完畢；你的電腦從「只能自己動手」變成「多一個 24 小時助手」。
CTA→訂閱＋下集預告＋置頂留言送完整 prompt 包。

**CH4（11:00–23:00）「怎麼安裝？我連終端機都沒開過」**［★核心跟操段：Mac 真實錄屏＋Win 黑曜石重建］
- 先破迷思：舊教學要你先裝 Node.js/npm——**現在不用了**，官方原生安裝法一行搞定。
- **Mac 實錄（約 7 分）**：Spotlight 搜 Terminal → 「終端機只是跟電腦打字聊天的窗口」去恐懼化 → 貼 `curl -fsSL https://claude.ai/install.sh | bash` → 跑完打 `claude` → 瀏覽器登入 → 回終端機看到歡迎畫面。
  - ✅ 檢核點卡①：「你現在應該看到：版本號＋模型名＋你所在的資料夾。」
- **Windows 重建段（約 4 分，黑曜石忠實重建）**：開始鍵搜 PowerShell → 認提示符（`PS C:\` 才是 PowerShell，沒有 PS 是 CMD——官方分辨法照搬）→ 貼 `irm https://claude.ai/install.ps1 | iex` → 同樣 `claude` 登入。補一句：建議順手裝 Git for Windows（官方建議，讓助手工具更齊）。
  - ✅ 檢核點卡②：同上，Windows 版樣式。
  - 誠實聲明（旁白帶到）：Windows 畫面是依官方文件忠實重建的示意，指令逐字照官方。
- 這章你帶走的是：一台裝好 Claude Code、登入完成的電腦。

**CH5（23:00–31:00）「裝好了，第一句話跟它說什麼？」**［Mac 真實錄屏跟操］
- 先講慘案（戲劇轉折）：唸出 @ww16*** 留言「下載資料夾全部被打散…我真的哭死」→ 所以第一個任務**永遠在練習資料夾裡做**。
- 跟操四步（每步 💬prompt 方塊＋旁白唸出）：
  1. 桌面新建資料夾「claude-練習」，隨手丟 10–20 個雜檔（截圖/PDF/文件）。
  2. 終端機 cd 進去（Mac 教「打 cd＋空格＋把資料夾拖進終端機」這招，零打字路徑）→ `claude`。
  3. 💬「這個資料夾裡有哪些檔案？幫我分類概述一下」→ 它唸得出來＝連上了。
  4. 💬 第一個自動化（見 §五 P4）：先要計畫、你說好才動手、動每個檔案都先問。
- 實錄它列計畫 → 你按好 → 它動手 → 完成清單。
- ✅ 檢核點卡③：「練習資料夾變成分類夾，且每個動作它都先問過你。」
- 這章你帶走的是：第一次成功的自動化＋「先給計畫再動手」這個保命習慣。

**CH6（31:00–36:00)「它會不會亂動我的檔案？」**［黑曜石＋官方文件卡］
- 定心丸（官方原文卡）：預設**動任何檔案前都會先徵求同意**，你按了才做。
- 三條安全家規（概念錨）：①新任務先在練習資料夾試 ②重要資料先備份再讓它碰 ③看不懂它要幹嘛就先按「否」再問它「你剛剛想做什麼？」。
- 回應 1356 讚警告：網路上的 skill/外掛先不要裝——EP01 用不到任何外掛，之後的集數會教你怎麼安全地挑。
- 這章你帶走的是：三條家規＋「按否不會壞事」的底氣。

**CH7（36:00–42:00）「卡住了怎麼辦？」**［常見卡點急救段：演 4 個真實錯誤畫面＋解法］

我已經建了一個練習資料夾，等一下的任務只准在這個資料夾裡進行。
任務：〔把你想自動化的事寫在這裡，例如：把檔案照類型整理進分類資料夾〕
規則：
1. 先給我步驟計畫，等我回覆「好」才開始動手
2. 要刪除或覆蓋任何檔案，一律先問我

## 六、跟操模式生產備忘（給製作階段）

- **Mac 實錄**：CH4/CH5 terminal 段可 asciinema/腳本重放全自動錄；HOOK 成品秀同。若要錄 GUI（Spotlight 開 Terminal 那幾秒）需老闆握手真螢幕錄影。
- **HOOK/CH5 練習資料夾素材**：不用真 Downloads 夾（個資風險）。用 `repo-template/generate-practice-folder.mjs` 產生 87 個示意雜檔（截圖/照片/文件/發票/簡報/試算表等分類、已驗證剛好 87 個對上旁白「八十七個檔案」），錄屏前先跑一次生成到乾淨的示範資料夾。
- **Windows 重建**：黑曜石 MetaMock 式終端機窗（PowerShell 深藍配色＋`PS C:\>` 提示符），指令逐字、輸出依官方文件重建；旁白誠實聲明示意。
- **錄屏遮蔽**：登入畫面 email 打碼；終端機自訂 prompt 若帶使用者名先改掉。
- **旁白節奏**：CH4/CH5 關鍵指令唸兩次、等畫面跑完才接話；其餘章正常速。
- **黑曜石共用元件**：預設 ExplainerObsidian 積木；只有 Windows 終端機窗需手刻 mockup（同 fb-autopost/MetaMock 接法）。
