## 腳本(六段)
### 1 鉤子
最現實的問題先解決:Claude Code 怎麼裝、要不要花錢?
### 2 你在這
地圖第 4 站,「認識」這一類的最後一站。裝完登入,我們就正式開工。
### 3 定義
安裝超簡單:一行指令就好(macOS/Linux 用 curl 那行;Windows 用 PowerShell)。裝完在專案資料夾輸入 claude,第一次會請你登入 Anthropic 帳號。費用方面:Free 方案不含 Claude Code;Pro,年付大約一個月 17 美金,就含 Claude Code;想大量用,Max,一個月 100 美金起,用量多很多。新手從 Pro 開始就夠。
### 4 例子 / demo
裝給我們的新聞小助手用:貼上安裝指令 → 看到 installed → 輸入 claude → 用瀏覽器登入 → 回到終端機看到 Welcome。就緒。
### 5 下一步
