## 腳本(六段)
### 1 鉤子
要用 Claude Code,得先選「在哪裡用它」。好消息:四個地方,你挑順手的就好。
### 2 你在這
地圖第 3 站,還在「認識」這一類。
### 3 定義
四個介面:終端機 CLI、VS Code 或 JetBrains 這類編輯器的擴充、獨立的桌面 App、還有瀏覽器的 claude.ai/code。關鍵一句:底層是同一個引擎,所以你的 CLAUDE.md、設定、MCP 在四個地方都通用——換地方不用重設。
### 4 例子 / demo
新手最簡單的起點是 VS Code 擴充:有 inline 改動對照、@檔案、計畫審查。但如果你想做「自動每天跑」的新聞小助手,瀏覽器版(雲端)就很適合——電腦關機它也能跑(這個第 24 站會講)。
### 5 下一步
先選一個你最常開的。下一站第 4 號:實際把它裝起來、登入,還有要哪種方案。
### 6 結尾 CTA
第 3 站打勾!訂閱繼續。來源:官方 overview,連結在描述。
