## 腳本(六段)
### 1 鉤子
你的 routine 在雲端跑——那「雲端」長什麼樣?就是 Claude Code on the web。
### 2 你在這
地圖第 24 站,「自動化與部署」這章最後一站。
### 3 定義
Claude Code on the web 就是在瀏覽器跑 Claude Code,完全不用本機環境。每個 session 跑在一個隔離的、Anthropic 管理的雲端 VM 裡。它適合:長時間任務(丟著去做別的)、處理你本機沒有的 repo、或同時平行跑多個任務。網址就是 claude.ai/code。
### 4 例子 / demo
我們的新聞小助手 routine,每天就是在這種雲端 session 裡跑。你打開 claude.ai/code,點進那次執行,就能看到它今天做了什麼、抓了哪些新聞、寄了沒。
### 5 下一步
自動化整章完成!下一站第 25 號,進最後幾章的第一個——安全:上線前,怎麼確保不出包。
