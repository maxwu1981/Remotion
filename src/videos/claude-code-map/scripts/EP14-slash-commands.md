### 3 定義
Slash commands 就是用 / 開頭、快速操控 session 的指令。新手最常用的幾個:/init 生成 CLAUDE.md、/model 換模型、/clear 清空對話、/compact 壓縮上下文、/agents 設定子代理、/usage 看用量。還有個重點:你「自訂的指令」現在已經併入 skills(連到第 17 站),所以自己做一個 /deploy 也行。
### 4 例子 / demo
做新聞小助手時的日常:卡住就 /clear、想省錢就 /model 換便宜的、要看花多少就 /usage。打一個 / 出來,清單就跳出來給你選。
