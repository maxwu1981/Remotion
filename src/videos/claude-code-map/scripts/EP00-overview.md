## 腳本(六段)

### 1 鉤子
你想用 AI 幫你自動做事,結果一打開 Claude Code,滿滿英文名詞——MCP、Skills、Hooks、Routines——直接被勸退?別怕。

### 2 你在這(地圖)
這支系列,用「一張地圖」解決。從「認識 Claude Code」開始,一路走到「自動化、部署、安全」。每一站,一個名詞、一支短片、一個編號。看到左上角的號碼,你就知道自己學到哪、下一步去哪。

### 3 定義(這系列怎麼運作)
而且我們會用「同一個任務」貫穿全部:做一個每天早上,自動幫你把關注主題的新聞整理成摘要、寄到 Email 的小助手。每學一個名詞,就把這個小助手往前推一步。

### 4 例子(地圖導覽)
地圖分七大類:認識、專案與記憶、規劃與控制、超能力、自動化、安全、還有模型與成本。圖上的虛線,就是它們怎麼「互相作用」——例如 CLAUDE.md 存在你的專案裡、Skills 又跟 MCP 分工合作。

### 5 下一步
規則很簡單:跟著號碼,從 1 走到 30。準備好了嗎?下一站,第 1 號:Claude Code 到底是什麼。

### 6 結尾 CTA
這是「Claude Code 新手地圖」系列。覺得有用,訂閱加按讚,跟著號碼一路學到 30。所有名詞解釋都來自 Anthropic 官方文件,放心學。
