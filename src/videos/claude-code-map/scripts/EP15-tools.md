## 腳本(六段)
### 1 鉤子
為什麼 Claude Code 不只會「講」,還能真的去「做」?因為它有工具。
### 2 你在這
地圖第 15 站,進入第四章「超能力」。工具就是驅動第 2 站那個迴圈「行動」的關鍵。
### 3 定義
Tools 是讓 Claude 能採取行動的能力。沒有工具,它只能回你文字;有工具,它能讀寫檔案、搜尋、跑指令、上網。內建分五類:檔案操作、搜尋、執行(跑 shell、測試、git)、上網、程式碼智慧。每用一個工具,結果就回饋進迴圈、決定下一步。
### 4 例子 / demo
新聞小助手抓新聞時:用「上網」工具搜尋與抓取、用「檔案操作」把摘要寫成 summary.md、用「執行」工具跑測試確認沒壞。你會看到它一個個呼叫這些工具。
### 5 下一步
內建工具是地基。下一站第 16 號:怎麼接「外部」工具,例如 Gmail——MCP。
### 6 結尾 CTA
第 15 站打勾!訂閱繼續。來源:官方 how-claude-code-works,連結在描述。
