## 腳本(六段)
### 1 鉤子
Claude Code 不是憑空工作的,它一定要待在「一個專案」裡。怎麼開始?
### 2 你在這
地圖第 5 站,進入第二章「專案與記憶」。
### 3 定義
專案就是你開的那個資料夾——Claude Code 會以它為家,讀裡面的檔案、在裡面動手。開好資料夾後,有個神奇指令:/init。它會自己掃過你的程式碼,生成一份起始的 CLAUDE.md,把 build 指令、慣例、專案結構先寫好。
### 4 例子 / demo
幫新聞小助手開個資料夾,叫 daily-news。在裡面啟動 claude,輸入 /init。幾秒後,左邊多了一個 CLAUDE.md,裡面已經寫好專案說明。我們之後就在這個資料夾長出整個小助手。
### 5 下一步
有了專案和那份 CLAUDE.md,下一站第 6 號:深入看 CLAUDE.md——它是整個專案的「記憶」。
### 6 結尾 CTA
第 5 站打勾!訂閱繼續。來源:官方 quickstart,連結在描述。
