## 腳本(六段)
### 1 鉤子
30 站走完了。我們花 90 秒,把整張地圖串成一條線——順便看小助手的成果。
### 2 你在這(回顧)
七大類:先「認識 Claude Code」(它是什麼、迴圈、在哪用、怎麼裝);再「專案與記憶」(專案、CLAUDE.md、auto memory、settings);接著「規劃與控制」(下指令、Plan mode、權限、context、checkpoints、斜線指令)。
### 3 串起來(中段)
然後給它「超能力」(tools、MCP、skills、subagents、hooks、plugins);再「自動化與部署」(headless、loop、routines、web);最後「安全與品質」跟「模型與成本」(security、sandbox、兩種 review、模型、/usage)。每一塊都靠虛線互相作用——CLAUDE.md 存在專案裡、skills 跟 MCP 分工、routines 把自動化送上雲端。
### 4 成果 / demo
我們的「每日新聞摘要小助手」:從第 1 站打開 claude,一路加上 Gmail MCP、摘要 skill、研究 subagent,最後用 routine 排程——現在每天早上 7 點,你信箱就自動有一份摘要。這就是 30 個名詞合起來的威力。
### 5 下一步
這只是新手地圖。想更進階?還有 Agent teams、Dynamic workflows、Agent SDK 等你探索。但最好的下一步,是你自己打開 Claude Code 做一遍。
### 6 結尾 CTA
謝謝你跟著走完 30 站!如果有用,訂閱、按讚、分享給也想學的朋友。所有定義都來自 Anthropic 官方文件,地圖與來源在描述裡。下個系列見!
