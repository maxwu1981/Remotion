## 腳本(六段)
### 1 鉤子
為什麼 Claude Code 能「自己」把一件事做完,而不是回你一段話就停?祕密是一個迴圈。
### 2 你在這
地圖第 2 站。上一站知道它是什麼,這站看它「怎麼運作」。
### 3 定義
官方叫它 agentic loop,三個階段一直循環:收集情境、採取行動、驗證結果。模型負責推理、工具負責動作;它會根據上一步學到的東西,決定下一步做什麼,把幾十個動作串起來,還會中途自我修正。重點:你也是迴圈的一部分,隨時能按 Esc 打斷、改方向。
### 4 例子 / demo
回到我們的新聞小助手。你說「幫我抓今天的 AI 新聞」,它會:搜尋怎麼拿資料(收集)→ 寫一小段程式去抓(行動)→ 跑跑看有沒有成功(驗證)→ 沒成功就修、再試。你會在畫面上一行一行看到它在想什麼。
### 5 下一步
看懂這個迴圈,你就看得懂它畫面上每一步在幹嘛。下一站第 3 號:這個迴圈,可以在哪些地方跑。
