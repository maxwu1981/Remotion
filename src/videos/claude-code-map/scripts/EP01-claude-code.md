## 腳本(六段)

### 1 鉤子
你一直聽到 Claude Code,但它到底是什麼?一句話:一個會「自己」讀你的專案、改檔案、跑指令的 AI 工具。

### 2 你在這(地圖)
這是地圖第 1 站,「認識 Claude Code」的起點。把它搞懂,下一步就是第 2 站:它背後怎麼運作。

### 3 定義(對照官方)
官方的說法是:Claude Code 是一個 agentic coding 工具。agentic 的重點是「能自己採取行動」,不只是回你一段文字——它能讀整個專案、跨好幾個檔案一起改、跑測試、還能用 git 幫你提交。而且最棒的是:你不一定要會寫程式,用講的就行。

### 4 例子 / demo
那在哪裡用?四個地方:終端機、VS Code 這類編輯器、桌面 App、還有瀏覽器。我們的「每日新聞摘要小助手」就從這開始——打開終端機,輸入 claude,登入帳號,然後直接對它說:幫我做一個每天寄新聞摘要的小工具。它就會開始規劃、動手。

### 5 下一步
一個重點先記住:Claude Code 要付費方案才能用,Pro 方案、年付大約一個月 17 美金就含了(這個第 4 站會細講)。下一站第 2 號:它背後的「代理迴圈」,看它怎麼一步步把事情做完。

### 6 結尾 CTA
第 1 站完成,地圖上打個勾!訂閱追下去,我們一起走到第 30 站。這集定義來自 Anthropic 官方 overview 文件,連結在描述裡。
