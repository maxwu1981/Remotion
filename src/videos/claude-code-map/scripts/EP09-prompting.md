# EP09 · 怎麼跟 Claude Code 下指令才有效?(第 9 / 30 站)

## GEO
- **標題**:Claude Code 指令怎麼下?講具體+給可驗證目標,一次到位
- **一句話描述**:對 Claude Code 講得越具體越好,並給它一個可驗證的目標(測試、預期輸出、截圖);複雜任務先探索再實作,效果最佳。
- **標籤**:Claude Code, prompt, 下指令, best practices, 新手教學

## 腳本(六段)
### 1 鉤子
同一個工具,有人用得神、有人用得爛,差別常常只在一件事:你怎麼下指令。
### 2 你在這
地圖第 9 站,進入第三章「規劃與控制」。
### 3 定義
官方的三個要點:第一,講具體——指明檔案、限制、參考範例。第二,給它一個「可驗證的目標」:測試案例、預期輸出、或一張設計截圖,它就能自己檢查對不對。第三,複雜任務先探索再實作。模糊的指令也能用,只是你要花更多時間來回修。
### 4 例子 / demo
反例:「幫我做新聞摘要」。好的版本:「讀 sources.txt 裡的網址,抓今天的標題,整理成最多 5 則繁中摘要,存成 summary.md;先寫一個會失敗的測試,再讓它通過。」差很多。
### 5 下一步
講清楚之後,還有個更穩的做法:讓它「先給計畫、你審過再動手」。下一站第 10 號:Plan mode。
### 6 結尾 CTA
第 9 站打勾!訂閱繼續。來源:官方 best-practices,連結在描述。
